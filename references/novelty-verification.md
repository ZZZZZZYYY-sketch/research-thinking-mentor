# Novelty verification

Before recommending a new algorithm for implementation or asserting originality, retrieve relevant classic and recent literature. Prefer original PDFs, arXiv versions, publisher pages, and official code. Verify titles, authors, dates, and actual algorithmic definitions. Construct a four-level comparison:

| Closest work | Problem similarity | Mathematical model overlap | Inference mechanism overlap | Experimental evidence overlap | Real remaining gap |
|---|---|---|---|---|---|

Do not infer absence of prior work from a few search results. Explicitly label: verified facts, interpretation, unverified hypotheses, and unsearched areas. If no web access, explain the limitation and supply targeted queries rather than claiming novelty. Cite sources with actual accessible URLs/DOIs; never fabricate references.
